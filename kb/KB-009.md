# Slow laptop: first checks
Tags: slow, performance, laptop, frozen, disk space
1. Restart the laptop, especially if it has been running for more than a week.
2. Check that at least 15 percent of disk space is free.
3. Install pending updates from Harbor Self Service.
4. Quit apps you are not using, and note which app uses the most memory or CPU.

If it is still slow, open a ticket with the laptop's asset tag, when it started and which apps are affected.
