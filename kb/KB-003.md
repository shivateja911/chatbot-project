# Set up or replace your MFA authenticator
Tags: mfa, two-factor, authenticator, new phone, lost phone
New phone and you still have the old one:
1. Go to https://account.lumenharbor.example, open Security, then Add method.
2. Scan the QR code with the new phone and approve the test prompt.
3. Remove the old phone from the list.

Lost or stolen phone: contact IT security immediately. Only a person at the helpdesk can reset MFA, after verifying identity.
Never approve an MFA prompt that you did not start. Report unexpected prompts to IT security.
